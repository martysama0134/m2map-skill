# /m2map — Metin2 Map Generator

An AI coding skill that generates and modifies **Metin2 client maps** — from a
description, from an existing map, or by driving the WorldEditor REMIX Python
API. It works by distilling the conventions of the 142 official Ymir/GF maps
into measured, cited rules rather than guessed ones.

Works with Claude Code, Cursor, Codex, Windsurf, Cline, Copilot and Gemini CLI.

## Modes

```
/m2map generate  snowy mountain pass, 3x3, frozen river west-east, ruined shrine
/m2map improve   d:/maps/metin2_map_foo   widen the road and add pines along it
/m2map audit     d:/maps/metin2_map_foo
/m2map merge     metin2_map_a1 metin2_map_a2 --layout 2x1
/m2map reskin    d:/maps/metin2_map_foo --to snow
/m2map server    d:/maps/metin2_map_foo   populate with level 30-40 mobs
```

`generate` resolves your description into an explicit **mapspec**, shows it to
you, and builds only once you approve — so every taste decision is arguable
before a byte is written, and the result is reproducible from `(spec, seed)`.

## What it knows

Mined from the corpus, not assumed. A sample of what turned out to be true:

- **There is no road texture in Ymir's art.** All 355 distinct terrain `.dds`
  were searched; roads are ordinary field textures. `metin2_map_a1`'s road web
  is `b/field/field 01.dds`.
- **Ground is a per-tile stipple at 1 m**, not region fill — median run length
  2 tiles, half of all connected components a single tile.
- **Heading is `roll`, not `yaw`**, snapped to 15 degrees. Zero non-integer
  rolls in 48,774 records. Trees are unrotated about two thirds of the time.
- **`server_attr` keeps only bits 0-2.** Copying the whole attribute byte —
  which the editor's own generator does — blocks every cell of the map.
- **Slope is bimodal**: 42% of cells under 2 degrees, 34% over 35, almost
  nothing between. Generating to a median produces terrain that exists nowhere.

`skills/m2map/reference/` holds the prose; `reference/catalog/` holds 21 MB of
measured facts behind it.

## Requirements

Python 3.9+, `numpy`, `Pillow`. No `python-lzo` needed — `server_attr` uses a
pure-Python LZO1X port, differentially verified against liblzo2.

**You do not need the map corpus to use this.** The distilled knowledge is
committed. `d:\maps` is only needed to re-mine the catalogs.

Copy `m2map.paths.example.json` to `m2map.paths.json` and point it at your
client pack and output directory. Nothing hardcodes a host path; every key is
also overridable by `M2MAP_<KEY>` environment variable.

## Install (Claude Code)

Claude Code does not auto-discover plugins under `~/.claude/plugins/local/`.
Register this repo as a marketplace, then install:

```
/plugin marketplace add <path to this repo>
/plugin install m2map@m2map
```

Restart Claude Code afterwards — existing sessions keep the previously loaded
version.

### Codex

The Codex plugin is `plugins/m2map/`; it is discovered via
`.agents/plugins/marketplace.json`. Point your Codex configuration at this repo.

### Other agents

Copy the relevant rule directory (`.cursor/`, `.windsurf/`, `.clinerules/`, or
`.github/copilot-instructions.md`) plus `skills/` into your project root.

## Using the library directly

The codecs are useful without the skill:

```python
from m2map.codec import height, tile, attr, areadata, server_attr

a = areadata.AreaData.load("000000/areadata.txt")
a.records[0].crc = 12345          # edits reach the bytes
open("000000/areadata.txt", "wb").write(a.to_bytes())
```

Untouched files round-trip byte-for-byte; edited ones re-render. 201 tests cover
this against the real corpus.

## Non-goals

- SpeedTree authoring (`.prt` to `.spt`) — the skill selects from existing trees.
- New 3D model authoring — it places `.gr2`/`.spt` assets, it does not make them.
- Replacing WorldEditorRemix or MapForge. It complements both and reads from both.
- Matching specific models from a screenshot. Screenshots are read for *style
  cues* only; there is no thumbnail catalog to pattern-match against, and
  guessing a CRC makes the object silently vanish in game.
